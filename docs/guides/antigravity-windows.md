# Antigravity 2.0 與 Antigravity IDE：Windows 安裝指引

## 安裝前準備

- 個人 Gmail 帳號（參考 [Google 帳號註冊指引](google-account.md)）
- Chrome 瀏覽器
- 安裝軟體的系統權限

## 安裝步驟

1. 前往 [Antigravity 官方下載頁](https://antigravity.google/download)。
2. 選擇 Antigravity 或 Antigravity IDE 的 Windows 版本並下載安裝程式。
3. 開啟下載的 `.exe` 安裝檔；若 Windows 顯示確認視窗，請先核對發行者與檔案來源，再允許執行。
4. 依安裝程式提示完成安裝。
5. 若已安裝 Antigravity，也可從應用程式右上角選擇 **Install IDE**。
6. 從「開始」選單啟動程式，使用個人 Google 帳號登入並選擇佈景主題。
7. 初次設定代理程式權限時，建議選擇 **Review-driven development**。
8. 只安裝課程需要的擴充套件與外掛。

## 安裝確認

1. 開啟一個測試資料夾。
2. 從選單開啟新終端機，確認 PowerShell 可正常使用。
3. 建立並儲存一個測試檔案。
4. 從代理面板送出簡短問題，確認登入與網路連線正常。

## 安全提醒

- 執行代理程式提出的 PowerShell 或其他終端機指令前，先確認內容及影響範圍。
- 不要把密碼、API 金鑰或 `.env` 內容貼進對話。
- 僅開啟來源可信的專案，並保留人工審查設定。
