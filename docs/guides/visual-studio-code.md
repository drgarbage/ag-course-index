# Visual Studio Code 安裝指引

Visual Studio Code（VS Code）是免費的程式碼編輯器，可用來開啟課程專案、編輯 Markdown 與程式碼，以及操作整合式終端機。

> Visual Studio Code 與 Visual Studio 是不同產品；本課程需要的是 Visual Studio Code。

請依你的作業系統選擇安裝指引：

- [Windows 安裝指引](visual-studio-code-windows.md)
- [macOS 安裝指引](visual-studio-code-macos.md)
