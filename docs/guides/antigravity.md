# Antigravity 2.0 與 Antigravity IDE 安裝指引

Antigravity 是管理多個本機代理程式的應用程式；Antigravity IDE 則提供程式碼編輯器、終端機與代理面板。請依你的作業系統選擇安裝指引：

- [Windows 安裝指引](antigravity-windows.md)
- [macOS 安裝指引](antigravity-macos.md)

目前索引僅列出課程支援的 Windows 與 macOS。其他系統請參考 [Antigravity 官方下載頁](https://antigravity.google/download)及[官方入門教學](https://codelabs.developers.google.com/getting-started-agy-ide?hl=zh-tw)。
