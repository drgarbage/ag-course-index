# Course 11－課堂用提示詞整理

來源：`class11/slides/slide.md`。投影片提供 prompt 結構而非完整 fenced 文字；以下依投影片列出的要素整理成可填寫模板。

## 企業文章封面圖

```text
請為以下內容生成一張企業用途的文章封面圖。

- 用途：[部落格封面／社群圖／活動海報]
- 主題：[文章摘要與關鍵意象]
- 風格：[淺色企業科技風／插畫／攝影]
- 構圖：[主體位置、留白區域、元素配置]
- 比例：[16:9／1:1／4:3]
- 限制：[不要科幻城市、機器人臉、真人肖像或其他禁用元素]
```

## Before／After 企業短片

```text
請生成一段 6 秒、16:9 的企業科技風短片，呈現導入 AI Agent 前後的工作差異。

- 場景：明亮、乾淨的辦公室與電腦桌面
- 主體：工作者、資料視窗與 dashboard
- 前 3 秒（Before）：多個視窗快速切換，試算表、聊天與文件散落，工作者手動整理報告
- 後 3 秒（After）：畫面轉為乾淨 dashboard，AI Agent 自動整理摘要卡片與圖表，工作者確認結果
- 鏡頭：平穩推進，以自然轉場連接 Before 與 After
- 風格：明亮、乾淨、企業培訓感
- 禁止：科幻城市、黑色霓虹、誇張機器人
```

## 課堂工作流設計

```text
請針對一個與工作相關的題目，設計一條 AI 工作流：
1. 封面圖 prompt：包含用途、主題、風格、構圖、比例與限制。
2. 影片 prompt：包含 Before／After 場景、動作、鏡頭與時間軸。
3. 表單設計：列出要收集的欄位與必填規則。
4. 分析報告：列出報告必須回答的三個核心問題。

題目：[公司文章／活動企劃／產品介紹／內訓課程／自訂題目]
```
