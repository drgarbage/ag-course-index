## LINE 行動 AI 祕書

```text
請幫我建立一個 LINE 行動 AI 祕書。

需求：
1. 使用 LINE Messaging API 與 Webhook 接收使用者訊息。
2. 使用 Gemini API 與 Function Calling 處理使用者意圖。
3. 支援三種服務：
   - 記帳：新增支出、查詢支出統計
   - 筆記：新增筆記、搜尋筆記
   - 待辦：新增待辦、列出待辦、標記完成
4. 提供快速指令：
   - /待辦：列出未完成待辦
   - /我的：顯示本月支出與待辦摘要
   - /說明：顯示可用功能
5. LINE 回覆要適合手機閱讀，文字簡短，避免 Markdown 格式。
```
