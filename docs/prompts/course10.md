來源：`class10/slides/slide.md`。

## 通用螢幕協作 Agent

```text
請進入 Plan Mode，先不要直接寫程式。

我想設計一個「通用螢幕協作 Agent」。

我希望她像一位長期合作的工作夥伴：
當我正在查資料、閱讀文件、寫企劃、整理專案，
或與 AI 工具討論時，
她可以理解我目前正在看的畫面與工作脈絡。

我可以用文字或語音叫她：
- 幫我記下這個結論
- 翻譯這段英文
- 把目前討論整理成 memo
- 幫我查一下這個資料
- 把這段補到專案紀錄

她應該在低干涉的情況下提供協助：
平時以 HUD、Overlay、Floating View、
Side Widget 或 Notification 這類方式待命，
需要時才展開完整面板。

請先幫我整理：
1. 使用者流程
2. UI 狀態
3. memo note 資料格式
4. 可使用的 Workspace 資料來源
5. 需要哪些 AI 能力
6. 驗收清單

限制：
- 先規劃，不要直接寫程式
- 以課堂可實作的範圍為主
- 保留文字輸入作為語音輸入備援
- memo note 要能保存截圖、摘要、翻譯、標籤、待辦與使用者備註
- 最後要能整理成 Markdown 工作摘要
```
