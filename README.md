> ⚠️ **輔助工具安裝** 若出現警示，請依以下方式開啟：
> * **Windows**：點選 **其他資訊** 並選擇 **仍要執行**。
> * **macOS**：點選右鍵選擇 **打開**，或至 **系統設定 > 隱私權與安全性** 點選 **仍要開啟**。
