# live-dev-init

Modular skill for development environment preflight checks and initialization.

## Installation
```bash
npx skills add drgarbage/ag-course-index --skill live-dev-init
```

## Features
- Probes and installs Git, GitHub CLI (`gh`), Node.js, Vercel CLI, Firebase CLI, and Gitleaks.
- Verifies `.nvmrc`, `.gitignore` configurations.
- Prepares Git Flow branches.
